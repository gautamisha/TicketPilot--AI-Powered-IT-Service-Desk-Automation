# TicketPilot--AI-Powered-IT-Service-Desk-Automation
AI-powered IT service desk automation system for ticket classification, priority assignment, automated routing and support analytics using Python and Flask.
TicketPilot is a Python-based IT service desk automation application designed to simplify support ticket management using machine learning and workflow automation.

The system analyses incoming IT support requests, automatically categorizes tickets into areas such as hardware, software, network and access issues, and assigns priority levels based on predefined rules. It helps route requests to appropriate support teams and provides a centralized dashboard to track ticket status and analyze recurring issues.

Key Features

AI-Based Ticket Classification: Categorizes support requests using machine learning and natural language processing.

Priority Assignment: Assigns High, Medium and Low priority levels based on ticket details.

Automated Ticket Routing: Directs requests to the appropriate support teams.

Ticket Management: Allows users to submit, view and track support requests.

Analytics Dashboard: Displays ticket statistics, category distribution and recurring issues.

REST API Integration: Provides API endpoints for ticket submission and management.

Technology Stack

Python, Flask, Scikit-learn, Pandas, MySQL, REST APIs, HTML, CSS and JavaScript.

Objective

To reduce repetitive manual IT support activities, improve ticket handling efficiency and demonstrate how AI and automation can improve enterprise IT service management.
